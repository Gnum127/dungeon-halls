# Инструкция по генерации изображений текстур — Чертоги подземелий

> Передай этот файл агенту, который будет генерировать изображения.
> Все файлы должны быть помещены сразу в целевые папки проекта.
>
> **Модель для генерации:** `gemini-3.1-flash-image` — вызывается ТОЛЬКО для
> генерации изображений. С кодом эта модель НЕ работает. Агент должен
> переключиться на неё через `tools.opencode.models` и использовать строго
> по назначению: один вызов = одна картинка.

## Общие требования

- **Формат:** PNG, 24-bit цвет + альфа-канал (прозрачность) где нужно.
- **Стиль:** изометрический / top-down dark fantasy, hand-drawn feel, не слишком
  мультяшный, не фотореалистичный. Ориентир — стиль Dungeondraft / Inkarnate.
- **Именование:** snake_case, английские названия, например `floor_stone_01.png`.
- **Все файлы складывать** в `frontend/public/sprites/` (подпапки ниже).

---

## 1. Текстуры ландшафта (тайлы)

> **Важно:** эти текстуры рисуются ПОД сеткой. Размер картинки должен быть
> кратным размеру клетки (`CELL_SIZE = 64px`), чтобы закрывать сразу несколько
> клеток. Края картинки должны бесшовно стыковаться: верх с низом, лево с право.

**Целевая папка:** `frontend/public/sprites/tiles/`

**Размер:** `1024×1024 px` (16×16 клеток при `CELL_SIZE = 64`). Целевой размер
плитки при рендере задаётся полем `size` в `public/sprites/manifest.json`
(`tileTextures[tile].size`) и должен совпадать со стороной картинки в пикселях.

**Требования к каждой текстуре:**
- Бесшовный тайлинг (seamless tile) — края стыкуются без видимых швов.
- Плитка повторяется по всей области покрытия.
- Достаточно деталей, чтобы повтор не бросался в глаза.
- Никакой прозрачности (полностью залитая область).

### Список тайлов:

| Название | Файл | Описание |
|----------|------|----------|
| Пол (камень) | `floor_stone.png` | Тёплый серый камень, обработанная плитка подземелья |
| Трава | `grass.png` | Зелёная трава с вариациями оттенков, мелкие детали |
| Камень (грубый) | `stone_rough.png` | Необработанный камень, скальная порода |
| Вода | `water.png` | Тёмно-синяя вода с рябью, полупрозрачность не нужна |
| Песок | `sand.png` | Песок пустыни/пещеры, мелкозернистая текстура |

## 2. Текстуры объектов

> **Важно:** эти текстуры рисуются ПОВЕРХ сетки. Объекты имеют произвольные
> размеры и не привязаны к клеткам. Каждый объект — одна картинка с прозрачным
> фоном.

**Целевая папка:** `frontend/public/sprites/objects/`

**Размер:** `1024×1024 px` (квадрат; сторона должна совпадать с размером файла).

**Требования к каждой текстуре:**
- Прозрачный фон (альфа-канал).
- Объект отцентрирован в изображении.
- Вид сверху (top-down), изометрический ракурс не нужен.
- Тень под объектом (полупрозрачная, тёмная).

## 3. Итоговая структура файлов

После генерации все файлы должны оказаться здесь:

```
frontend/public/sprites/
├── tiles/
│   ├── floor_stone.png
│   ├── grass.png
│   ├── stone_rough.png
│   ├── water.png
│   └── sand.png
└── objects/
    ├── table_wooden.png
    ├── chair_wooden.png
    ├── chest_wooden.png
    ├── barrel_wooden.png
    ├── bush_green.png
    ├── rock_boulder.png
    └── tree_oak.png
```

## 4. Проверка

После генерации проверь:
- [ ] Все файлы существуют по указанным путям.
- [ ] Размеры корректны (тайлы и объекты 1024×1024 — совпадают с `size` манифеста).
- [ ] У тайлов нет прозрачности, у объектов есть.
- [ ] Тайлы бесшовно стыкуются (проверяется тайлингом 2×2).
- [ ] У объектов есть тень.
