## Этап 1. Ядро редактора (MVP) ← СЛЕДУЮЩИЙ

- [ ] Модель данных карты: тайлы (террейн), объекты; квадратная сетка
- [ ] Canvas-рендер: сетка, зум/панорамирование
- [ ] Кисть террейна: выбор типа плитки, рисование по клеткам
- [ ] Палитра типов террейна (пол, вода, стены-блоки…)
- [ ] Объекты: первые 5–10 (дверь, лестница, стол, стул, сундук, факел)
- [ ] Инструмент «выбор/перемещение/удаление объекта»
- [ ] Undo/redo
- [ ] Сохранение/загрузка проекта в JSON-файл
- [ ] Экспорт PNG (в масштабе 1 клетка = N px)

## Этап 2. Генератор локаций

- [ ] Генератор «комнаты + коридоры» (классический данж)
- [ ] Генератор пещер (cellular automata)
- [ ] Параметры генерации (размер, связность, плотность комнат)
- [ ] Результат генерации открывается в редакторе для доработки — ключевая фича

## Этап 3. Расширения (порядок по выбору)

- [ ] Гексагональная сетка (flat-top и pointy-top)

- [ ] Стены/двери как отдельные сущности, освещение
- [ ] Экспорт Universal VTT (.uvtt) — нужен предыдущий пункт
- [ ] Экспорт SVG/PDF для печати
- [ ] Библиотека объектов: расширяемый каталог
