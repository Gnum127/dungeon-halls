# Алгоритмы генерации

Все генераторы — чистые функции `(params, rng) → GenerationResult`.
Детерминизм гарантирован контрактом: фиксированный seed + те же параметры =
побитово та же карта (см. `rng.ts`). Любая замена PRNG сломает сохранённые
сид-ссылки и будет поймана known-answer тестами `rng.test.ts`.

## Данж «комнаты + коридоры» (`dungeon.ts`)

1. Всё заполняется стенами.
2. До `roomAttempts` раз пробуем разместить комнату 3×3…8×8 в случайной
   позиции с зазором ≥1 клетки от уже стоящих (`layoutRooms`).
3. Комнаты вырезаются полом; между центрами комнат i−1 → i прорезаются
   L-образные коридоры (порядок горизонталь/вертикаль выбирает rng).

Связность гарантирована построением: цепочка «каждая комната ↔ предыдущая»
делает граф комнат деревом, коридоры не пересекают внешнюю рамку.

Минимальный размер карты: 6 (комната 3 + зазор с обеих сторон + рамка).

## Пещеры (cellular automata, `caves.ts`)

1. Сплошной шум: каждая клетка — стена с вероятностью `fillProbability`.
2. `smoothingIterations` раз применяется правило: клетка становится стеной,
   если среди её 8 соседей стен ≥5, иначе полом (границы считаются стенами).
3. Финальная рамка стен по периметру.

Типичные параметры: fillProbability 0.42–0.48, iterations 3–5.
Меньше итераций — зернистые пещеры, больше — крупные гладкие каверны.

## Интеграция с редактором

Результат передаётся в editor командой `replaceMap`: одна запись истории,
undo возвращает прежний документ целиком (включая объекты). Объекты при
генерации очищаются атомарно — их координаты не имеют смысла на новой сетке.
