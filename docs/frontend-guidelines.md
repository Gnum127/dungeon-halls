## Слои и направление зависимостей

```
src/
  app/        композиция: провайдеры, оболочка, глобальные стили, i18n
  config/     конфигурационные константы (размеры карты, лимиты)
  editor/     фича «редактор карты» (векторная модель v6)
    model/    MapModel, TerrainRegion, WallSegment, Door, StairsPolygon, команды, IO
    render/   векторный рендер: регионы, лестницы, стены с телом, двери, объекты, свет
    tools/    инструменты построения фигур + стены + двери + лестницы + объекты
    hooks/    кастомные хуки для canvas-взаимодействия
    components/  UI-панели инструментов
  generator/  фича «генератор локаций»
  shared/     общие константы и типы между фичами (tiles.ts, point.ts, id.ts, random.ts)
```

- Зависимости только вниз: `app → editor/generator → shared`.
- `config/` — чистые константы, импортируется откуда угодно без ограничений.
- **Исключение (composition root):** `EditorPage` де-факто собирает страницу
  приложения и может импортировать `@/generator` (только через публичный
  `index.ts` генератора). Направление строго одно: editor импортирует
  generator, обратное запрещено. Других межфичевых импортов нет.
- Публичный API фичи — её `index.ts`; соседние слои импортируют только его.
- Межпапочные импорты между верхними слоями (`app`, `editor`, `generator`,
  `shared`) — через алиас `@/`; относительные пути — внутри одной фичи
  (между её подпапками) и внутри одной папки.

## Редактор: однонаправленный поток (векторная модель v6)

`событие canvas → команда → новая модель → перерисовка`

1. **Модель** — чистые типы TS, без React/DOM/Canvas:
   `MapModel { version: 6, grid, regions, walls, doors, stairs, objects, lights }`.
   - `TerrainRegion` — полигон с типом покрытия и z-order
   - `WallSegment` — ломаная с телом (авто — замкнутый контур, ручная — открытая)
   - `Door` — самостоятельный проём: отрезок `a`–`b` + угол створки `openAngle`
     (0 = закрыта, знак = сторона), `imageId`
   - `StairsPolygon` — контур лестницы (оверлей: без заливки и авто-стен)
   - `MapObject` — без изменений (клеточное размещение)
   - `MapLight` — без изменений (клеточное размещение)
2. **Изменения только командами**: `type Command`, функция
   `applyCommand(model, cmd): MapModel`. Иммутабельность обязательна:
   верхнеуровневый объект всегда новый, массивы копируются при записи.
3. **Undo/redo** — стек версий модели с ограничением глубины
   (`HISTORY_LIMIT`, например 50). Отдельная логика отмены запрещена.
4. **Хранилище вне React**: стор с интерфейсом `getModel()/subscribe()/dispatch()`;
   компоненты подключаются через `useSyncExternalStore`. Модель не хранить
   в `useState`. Интерфейс стора стабилен.
5. **Рендер** — чистая функция `renderMap(ctx, model, viewport, sprites?)`.
   - Регионы сортируются по `zOrder`, рендерятся полигонами с тайлингом текстур
   - Стены рендерятся с телом (утолщение от осевой линии); замкнутый контур —
     одним замкнутым путём (canvas `closePath`, SVG `Z`), открытая ломаная —
     круглыми концами; проёмы дверей вырезают интервал стены плюс зазор 1/6
     клетки (`splitWallByDoorGaps`), разрезанный контур рендерится открытыми
     прогонами
   - Двери — по отрезку `a`–`b`: закрытая — текстура/жирная заливка по проёму,
     открытая — створка, повёрнутая вокруг петли `a` на `openAngle`; хит-тест
     инструмента — по раме проёма `a`–`b` в мировых координатах
   - Лестницы — контур + поперечные ступени, без заливки
   - Объекты и свет — как раньше (поверх регионов)
   - Сетка — точечная: точка в углу клетки рисуется, если покрыта любая из
     смежных клеток (непустые регионы + лестницы); дубликаты точек схлопнуты
   - Подсветка при наведении: клетка целиком, для текстурных инструментов —
     квадрант 0.5×0.5; плюс точки-кандидаты снапа с подсветкой ближайшей
   - Снап — общий модуль `model/snap.ts`: `characteristicPoints` (9 узлов
     0.5×0.5 при покрытии, 4 угла без), `nearestSnapPoint` и
     `snapToCellCharacteristics` (стены — с 16.4; двери/лестницы — этапы
     17/18); покрытие — `createCoverageTester` из `model/coverage.ts`
   - React владеет панелями UI, но не содержимым canvas.

## Компоненты и хуки

- Функциональные компоненты; props — `interface XxxProps`.
- Логика — в кастомных хуках `useXxx`; компоненты тонкие.
- Данные вниз, события вверх (`onXxx`). Бизнес-логики и fetch в JSX нет.
- Прямой DOM-доступ запрещён, кроме `ref` на canvas.
- `useEffect` — только синхронизация с внешним миром (canvas, localStorage,
  события окна), не для вычисления данных.
- Производные данные — чистые функции-селекторы `selectXxx(model)`.

## Данные и сериализация

- Модель сериализуется в JSON как есть (MapModel v6).
- Загрузка — валидация схемы v6. Версии ≠ 6 → `MapLoadError`.
- Миграции старых форматов НЕ ПОДДЕРЖИВАЮТСЯ (релиза не было).
- Полигоны сериализуются как `number[][]` (массив пар [x, y]).
- Чтение/запись файлов проекта — модуль `io.ts` внутри фичи `editor/model/`.

## Псевдорандом текстур

- Пул текстур для каждого типа тайла в `sprites/manifest.json` секцией `tilePools`
- При рендере региона: виртуальная сетка с шагом `cellSize`, для каждой ячейки
  `hash(tileX, tileY) % poolSize` → индекс текстуры
- Детерминировано: тот же регион всегда тайлится одинаково, без хранения в модели
- PRNG: `hashFromCoords(x, y)` / `pickIndexFromCoords(x, y, size)` из
  `shared/random.ts` (собственный целочисленный хеш, без зависимости от `generator/`)
- Fallback: нет пула → одиночный спрайт тайла, иначе сплошной цвет `TILE_COLORS[typeName]`

## Авто-стены

- Чекбокс «Авто-стены» в панели «Ландшафт» (по умолчанию ВКЛ)
- После коммита региона вычисляется точная граница покрытия → `WallSegment[]`
- Покрытие — painter-order: регионы наносятся по `zOrder` (возр.), `empty`
  вычитает уже нанесённое («верхний побеждает»); заливка поверх стёртого
  восстанавливает покрытие и не оставляет «призрачных» стен
- Boolean-операции над полигонами (`polygon-clipping`): точные кромки без
  клеточной «лесенки», в т.ч. диагонали
- Один `WallSegment` на замкнутый контур (`points[0] === points[last]`);
  вложенные контуры (дыры) — отдельные сегменты; id — детерминированный хеш
  канонического контура; ручные стены сохраняются, двери НЕ привязаны к стенам
- Стены коммитятся ОДНОЙ составной командой `addRegionWithWalls`
  (undo возвращает и регион, и стены)

## Запреты

- `any`, `enum` (использовать union-типы / `as const`)
- Классовые компоненты
- Русский текст в JSX вне `ru.json`
- Inline-стили, кроме динамики canvas (координаты, размеры)
- Взаимные импорты фич, импорт мимо публичного `index.ts`
- Клеточные рёбра `WallEdge`/`WallSide` (N/E/S/W) — удалены, использовать `WallSegment`
- `gridType`, `hex-flat`, `hex-pointy` — удалены, только квадратная сетка
- UVTT-экспорт — удалён полностью
