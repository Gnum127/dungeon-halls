# Гайдлайны фронтенда — Чертоги подземелий

Цель — предсказуемый результат от сессии к сессии. Правила обязательны.
Если правило мешает задаче — не молча нарушать, а обсудить и обновить этот файл.

## Слои и направление зависимостей

```
src/
  app/        композиция: провайдеры, оболочка, глобальные стили, i18n
  editor/     фича «редактор карты»
  generator/  фича «генератор локаций»
  shared/     общие константы и типы между фичами (tiles.ts)
```

- Зависимости только вниз: `app → editor/generator → shared`.
- **Исключение (composition root):** `EditorPage` де-факто собирает страницу
  приложения и может импортировать `@/generator` (только через публичный
  `index.ts` генератора). Направление строго одно: generator editor
  не импортирует. Других межфичевых импортов нет.
- Публичный API фичи — её `index.ts`; соседние слои импортируют только его.
- Межпапочные импорты между верхними слоями (`app`, `editor`, `generator`,
  `shared`) — через алиас `@/`; относительные пути — внутри одной фичи
  (между её подпапками) и внутри одной папки.

## Редактор: однонаправленный поток

`событие canvas → команда → новая модель → перерисовка`

1. **Модель** — чистые типы TS, без React/DOM/Canvas:
   `MapModel { version, width, height, tiles, objects }`.
2. **Изменения только командами**: `type Command`, функция
   `applyCommand(model, cmd): MapModel`. Иммутабельность обязательна:
   верхнеуровневый объект всегда новый, изменённые поля копируются при
   записи (tiles — типизированный массив; копировать его целиком на каждый
   штрих допустимо до появления проблем производительности, дальше — чанки).
3. **Undo/redo** — стек версий модели с ограничением глубины
   (`HISTORY_LIMIT`, например 50). Отдельная логика отмены запрещена.
4. **Хранилище вне React**: стор с интерфейсом `getModel()/subscribe()/dispatch()`;
   компоненты подключаются через `useSyncExternalStore`. Модель не хранить
   в `useState`. Интерфейс стора стабилен: если понадобится библиотека
   (например zustand), она заменит реализацию, не затронув компоненты.
5. **Рендер** — чистая функция `renderMap(ctx, model, viewport)`.
   React владеет панелями UI, но не содержимым canvas.

## Компоненты и хуки

- Функциональные компоненты; props — `interface XxxProps`.
- Логика — в кастомных хуках `useXxx`; компоненты тонкие.
- Данные вниз, события вверх (`onXxx`). Бизнес-логики и fetch в JSX нет.
- Прямой DOM-доступ запрещён, кроме `ref` на canvas.
- `useEffect` — только синхронизация с внешним миром (canvas, localStorage,
  события окна), не для вычисления данных.
- Производные данные — чистые функции-селекторы `selectXxx(model)`.

## Данные и сериализация

- Модель сериализуется в JSON как есть; при загрузке — валидация схемы
  и миграция по полю `version`. Старые файлы не должны ломать приложение.
- Чтение/запись файлов проекта — модуль `io.ts` внутри фичи `editor`.

## Тесты

- Unit-тесты обязательны для чистой логики: модель, команды, генераторы,
  селекторы, миграции.
- RTL-тесты — для интерактивных частей оболочки.
- Файл теста рядом с кодом: `Xxx.test.ts(x)`.
- Исправление бага начинается с падающего теста.

## Запреты

- `any`, `enum` (использовать union-типы / `as const`)
- Классовые компоненты
- Русский текст в JSX вне `ru.json`
- Inline-стили, кроме динамики canvas (координаты, размеры)
- Взаимные импорты фич, импорт мимо публичного `index.ts`
