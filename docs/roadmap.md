## Этап 1. Ядро редактора (MVP) ← СЛЕДУЮЩИЙ

Каждый пункт — размер одной сессии: реализация + самопроверка по
`docs/quality-checklist.md` + вердикт PASS от сабагента `@reviewer`.
Порядок пунктов соблюдать: модель → стор → рендер → ввод.

- [ ] 1.1 Каркас фичи `editor/`: структура папок, публичный `index.ts`,
      страница редактора в `app/` вместо заглушки
- [ ] 1.2 Модель `MapModel { version, width, height, tiles, objects }`,
      фабрика createEmptyMap + unit-тесты
- [ ] 1.3 Команды (SetTile и др.) + applyCommand, иммутабельность;
      тесты включая края поля и повторное применение
- [ ] 1.4 EditorStore: getModel/subscribe/dispatch, история с HISTORY_LIMIT;
      хук useEditor на useSyncExternalStore; тесты undo/redo, включая
      сброс redo-ветки после новой команды
- [ ] 1.5 CanvasView: renderMap(ctx, model, viewport) — единая точка рендера,
      задел под будущий спрайтовый режим; сетка (MVP — только квадратная,
      гексы — Этап 3), DPR, зум колесом, пан;
      чистая функция мышь→клетка + unit-тесты (зум ≠ 1, скролл)
- [ ] 1.6 Кисть террейна: drag-рисование через команды; один штрих =
      одна команда в истории (coalescing до dispatch)
- [ ] 1.7 Палитра террейнов (пол, трава, вода, камень, песок, стена-блок,
      пустой тайл = ластик) + панель инструментов;
      RTL-тест, i18n-ключи сразу в ru.json и en.json
- [ ] 1.8 Объекты (дверь, лестница, стол, стул, сундук, факел):
      размещение, выбор, перемещение (одно перетаскивание = одна команда
      в истории), удаление
- [ ] 1.9 io.ts: сохранение/загрузка JSON, валидация схемы, миграция по
      полю version; roundtrip-тесты + тест битого файла
- [ ] 1.10 Экспорт PNG с выбором масштаба px/клетку
- [ ] 1.11 Горячие клавиши: Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z, B кисть, E ластик
- [ ] 1.12 Полировка MVP: подсветка клетки под курсором, статусбар координат
