# Печать карты (SVG и PDF)

Кнопки **Export SVG** и **Export PDF** (рядом с Export PNG) выводят карту на
печать. Код: `print/svg.ts` (вектор), `print/pdf.ts` + `print/pages.ts`
(многостраничный PDF), `tools/pngExport.ts` (страничный растр).

## Общие свойства

- **Чекбокс «Печатать источники света»** (default off) — один контрол для
  SVG и PDF. На экране в canvas свет рисуется всегда.
- Спрайтовый режим отображения игнорируется: SVG — всегда цветной
  векторный, PDF печатает цветной растр через `renderToCanvas`.
- Сетка только квадратная: гексагональные сетки удалены в этапе 14; сетка —
  точечная (точки в углах покрытых клеток), сплошных линий нет.
- Цвета — единственный источник: `render/colors.ts`. Порядок слоёв печати
  повторяет `render/renderMap.ts`: регионы (по `zOrder`) → лестницы → точечная
  сетка → объекты → стены → двери; свет — опционально.

## SVG

`buildSvg(model, { includeLight }) → string` — чистая функция без DOM.

- Единица координат: 64 units/клетку (`SVG_UNITS_PER_CELL`); толщины стен
  (тело + контур) и дверей пропорциональны клетке.
- Числа — фиксированный формат (3 знака): float-координаты полигонов не
  ломают детерминизм «байт в байт».
- Регионы — полигоны `region.polygon` цветом `TILE_COLORS[tileType]`;
  стены — ломаные `wall.points` (замкнутый контур одним путём с `Z`, тело
  сгруппировано по толщине, у каждой группы свой `stroke-width`); двери —
  прямоугольники по отрезку `a`–`b`, открытая створка — по `doorLeafEnd`;
  лестницы — контур + ступени (`stairsStepSegments`), без заливки.
- 8-значный hex с альфой (#RRGGBBAA, CSS Color 4) — браузеры и Inkscape
  понимают; экзотические не-браузерные парсеры могут нет.

## PDF

`exportMapToPdf(model, options)` — только квадратная сетка. RangeError-guard
как defense-in-depth поверх дизейбла кнопки.

Параметры панели:

| Параметр      | Значения            | Геометрия                                                          |
| ------------- | ------------------- | ------------------------------------------------------------------ |
| Бумага        | A4 / A3 / Letter    | pt-размеры в `PAPER_PT`; страница округляется ВНИЗ до целых клеток |
| Ориентация    | книжная / альбомная | стороны листа меняются местами                                     |
| Размер клетки | 1" / 0.5"           | 1" — стандарт D&D (5 футов); 0.5" — компакт                        |

- **Разбивка**: `paginateMap` режет карту слева направо, сверху вниз;
  клетки не режутся, неполная последняя колонка/ряд дают ПОЛЯ (полный
  размер страницы в опции `pageSize`), контент прижат к левому верхнему
  углу — иначе страницы растянулись бы до разного масштаба.
- **Растр страниц**: `PRINT_DPI = 180` DPI × cellInches px/клетку (180 при
  1", 90 при 0.5"). Лимиты canvas считаются ОТ СТРАНИЦЫ — огромная карта
  печатается постранично без ограничений полной карты.
- **Сборка**: jsPDF (`unit: 'pt'`, `addImage` PNG на весь лист), Title из
  константы `PDF_TITLE`. jsPDF грузится динамическим `import()` — не
  попадает в стартовый бандл.
- **Предпросмотр числа страниц** в панели считается теми же чистыми
  функциями (layout + paginate) ДО экспорта; предупреждение при >50
  страницах (`PDF_MANY_PAGES`).

## Ручная проверка печати (при изменениях)

1. Откройте карту с полом, стеной, дверью и объектом.
2. Export SVG → откройте файл в браузере и в Inkscape: точечная сетка на
   месте (точки в углах покрытых клеток), точки не двоятся, цвета совпадают
   с холстом.
3. Export PDF (A4, книжная, 1") → распечатайте: линейкой проверьте клетку
   — ровно 25.4 мм; стены не двоятся; поля на неполных страницах.
4. Повторите с чекбоксом «Печатать источники света»: круги появились
   (SVG) / на растре (PDF); без чекбокса — их нет.
