# Чертоги подземелий (dungeon-halls)

Веб-редактор батлмапов для D&D: рисование карт на сетке, расстановка
объектов и процедурная генерация локаций — с возможностью дорабатывать
сгенерированное вручную.

## Запуск для разработки

Требуется Node.js LTS (v20+).

```powershell
cd frontend
npm install
npm run dev
```

Dev-сервер: http://localhost:5173
