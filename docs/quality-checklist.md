## Обязательные проверки (любое изменение)

- [ ] `npm run lint` — 0 ошибок (в `frontend/`)
- [ ] `npm run test:ci` — все тесты зелёные
- [ ] `npm run build` — сборка и проверка типов без ошибок
- [ ] Новые зависимости не добавлены без явного согласия автора
- [ ] Документация актуальна: пункт roadmap отмечен `[x]`, новые
      архитектурные решения отражены в AGENTS.md / frontend-guidelines.md

## Критерии по типам изменений

### Модель и логика (`editor/model/`, `generator/`, чистые модули)

- [ ] Нет импортов React/DOM/Canvas; функции чистые, данные иммутабельны
- [ ] Unit-тесты на каждую команду/генератор/селектор, включая края:
      пустая карта, границы поля, повторное применение команды
- [ ] Сериализация roundtrip: save → load → модель идентична исходной
- [ ] Загрузка битого/чужого JSON не ломает приложение (валидация + понятная ошибка)
- [ ] Все инварианты модели проверены тестами

### Store и история

- [ ] Компоненты получают модель только через стор + `useSyncExternalStore`;
      дублирования модели в useState нет
- [ ] Undo/redo покрыт тестами: последовательность команд, отмена до начала,
      redo после новой команды (ветка сбрасывается)
- [ ] Глубина истории ограничена константой

### UI (компоненты, панели)

- [ ] Все строки через `t()`; ключи добавлены в ru.json И en.json
- [ ] Стили в CSS Modules; цвета/отступы через переменные `:root`
- [ ] Интерактивный компонент имеет RTL-тест
- [ ] Критичные действия доступны с клавиатуры (undo/redo, выбор инструмента)

### Canvas и рендер

- [ ] `renderMap(ctx, model, viewport, sprites?)` — чистая функция, модель не мутирует
- [ ] Координаты мышь→мир вычисляются функцией с unit-тестом
      (включая зум ≠ 1 и скролл)
- [ ] Перерисовка подписана на стор, лишних циклов рендера React нет

## Цикл ревью

Если вердикт `@reviewer` = FAIL: внести исправления по всем блокирующим и
важным замечаниям (пожелания — по согласованию с автором) и вызвать
повторное ревью. Всего **не более 5 вызовов `@reviewer` суммарно на задачу**.
Если после пятого вызова остаётся FAIL — остановиться, не помечать задачу
выполненной и сообщить автору список оставшихся замечаний.

### Генераторы (`generator/`)

- [ ] Детерминизм: одинаковый seed + параметры → побитово та же сетка
      (known-answer тесты PRNG не тронуты)
- [ ] Все границы параметров дают RangeError (размеры, attempts,
      probability, iterations — обе стороны диапазона)
- [ ] Значения тайлов результата ∈ палитры; рамка стен по периметру
      (для наземных алгоритмов)
- [ ] Специфичные инварианты: связность данжа (flood-fill), отсутствие
      пересечений комнат, стабильность пещер после итераций

### Векторная модель (`editor/model/`, MapModel v6)

- [ ] `TerrainRegion`: ≥3 вершин, полигон не самопересекается (валидация при
      добавлении → RangeError)
- [ ] `zOrder` автоинкремент: каждый новый регион получает `max(zOrders) + 1`
- [ ] `WallSegment`: ≥2 точек, толщина ≥ 0; авто-стена — замкнутый контур
      (`points[0] === points[last]`), ручная — открытая ломаная
- [ ] `Door`: самостоятельный проём `{ id, a, b, openAngle, imageId }`; `a`/`b`
      конечны и не совпадают, `|openAngle| ≤ 150`, двери НЕ привязаны к стене
- [ ] `StairsPolygon`: ≥3 вершин, без самопересечений; оверлей (без стен/заливки)
- [ ] `addRegionWithWalls`: ОДНА запись истории, undo возвращает и регион, и стены
- [ ] IO v6: только v6, чужая версия → MapLoadError; roundtrip детерминирован
- [ ] Авто-стены: один `WallSegment` на замкнутый контур; вложенные контуры —
      отдельные сегменты; `empty`-регионы вычитаются как дыры; id детерминированы

### Векторный рендер (`editor/render/`)

- [ ] Порядок слоёв: регионы (по zOrder) → лестницы → точечная сетка → объекты →
      стены → двери → свет
- [ ] Регионы сортируются по zOrder (меньший снизу), рендерятся полигонами
- [ ] Точечная сетка: `coverageGridPoints` — единый источник (canvas + SVG),
      точки только в углах покрытых клеток, общие углы дедуплицированы
- [ ] Тайлинг текстур: детерминизм (тот же регион = те же текстуры),
      fallback на цвет при отсутствии пула
- [ ] Стены: тело утолщается на `thickness * cellSize`; замкнутый контур —
      один замкнутый путь (`closePath`/`Z`), открытая — круглые концы; стыки round
- [ ] Проёмы дверей геометрически разрывают стену: интервал `a`–`b` + зазор
      1/6 клетки с каждой стороны (`splitWallByDoorGaps`), canvas и SVG/PDF из
      одного источника; разрезанный замкнутый контур — открытые прогоны
- [ ] Двери: закрытая — по отрезку `a`–`b` (текстура/заливка), открытая —
      створка вокруг петли `a` на `openAngle` (текстура не поворачивается)
- [ ] Лестницы: контур + ступени (`stairsStepSegments`), БЕЗ заливки и авто-стен;
      выделенная лестница — замкнутый контур `HIGHLIGHT_COLOR` (`drawStairsSelection`)
- [ ] Culling: видимые регионы/стены по bounding-box, вне viewport не рисуются
- [ ] FakeCtx-тесты на каждый элемент рендера (регион, стена, дверь, лестница, тайлинг)

### Сетка и снап (этап 16)

### Спрайты (`editor/render/sprites/`, см. README там же)

- [ ] Валидация манифеста: битый JSON / неизвестные ключи / чужая version

- [ ] Отказоустойчивость загрузки: 404 манифеста → пустой атлас без

- [ ] Дедупликация параллельных запросов одного пути; кэш только успешных

### Печать SVG/PDF (`editor/print/`, см. README там же)

- [ ] Единственные источники: цвета из `render/colors.ts`, геометрия

- [ ] Свет в печати только по чекбоксу (default off), флаг доходит

- [ ] Предпросмотр числа страниц считается теми же чистыми функциями,
