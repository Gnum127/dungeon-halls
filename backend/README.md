# backend — заглушка

Серверная часть пока не нужна: приложение полностью клиентское, проекты карт
хранятся в JSON-файлах на стороне пользователя.

FastAPI будет развёрнут здесь, если появятся серверные задачи
(хранение проектов, шеринг карт по ссылке). См. `docs/roadmap.md`, Этап 4.

Ориентир стека: Python 3.10+, FastAPI, SQLite (файл в `data/`, гитигнорится).
